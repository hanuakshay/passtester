🔐 PassTester

A simple and beginner-friendly tool to test password strength and understand basic security concepts.
---
# What is this?

If you're starting in cybersecurity, it's important to understand what makes a password **weak or strong**.

This project helps you learn:

-  How weak passwords are identified  
-  Common mistakes users make  
-  Basic password security practices  

It’s a simple Python-based tool — lightweight and easy to run.
---
##  Features

-  Checks password strength  
-  Detects weak patterns (like "12345", "password")  
-  Beginner-friendly output  
-  Fast and simple CLI tool
